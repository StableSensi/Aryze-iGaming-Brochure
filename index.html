05For your developers

One call to the API.

Authenticate, initiate, receive the webhook. Our quickstart is timed at about five minutes.

# base url
https://payment-api.openfinance.aryze.io

# initiate a payment
curl -X POST /v1/payments/initiate \
  -H "Authorization: Bearer sk_test_…" \
  -d '{ "amount": 100.50, "currencyCode": "EUR" }'

# response
{ "flowUrl": "https://payment.aryze.io/...", "status": "PENDING" }
